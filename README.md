# PC Building Simulator Manual APWorld
This manual works with any new save game. It expects the use of two mods, installed using BepInEx (see an Archipelago guide, such as the one for TUNIC for instance, for more on installing BepInEx), which are provided by NexusMods:
- Seba Fixes: https://www.nexusmods.com/pcbuildingsimulator/mods/144?tab=description
- Configuration Manager (Included with Seba Fixes)
## Instructions
1. After installing the mods, begin a new game (I haven't tested with Hard mode, but I imagine that should probably work too).
2. (Optional) Open the configuration manager with F1, go into "Seba Fixes 1.16.0", and disable "More Daily Jobs" (unless you purposefully want more of them, more power to you).
3. Press F2 to open Seba Fixes itself and press both "Gain $1000000" and "Gain 1000000K" to gain infinite money and fully level up (for job access).
4. (Optional) You can also enable "Show hidden objectives" and "Show diagnose objectives" for assistance with knowing what is needed for a job. Logic accounts for these.
5. Clear all the spam emails.
6. To start a job line, click "Generate" next to it.
## Important Notes
- While we can spawn story jobs, note that for every day that passes in-game, you will receive a handful of jobs of which can be either story or randomized. There wasn't much I could do to prevent these from spawning, so to prevent any of these jobs from expiring that you might not be able to complete yet, be sure to always accept the job, then if you can't do it yet, stick the PC into storage when it arrives. A job will never expire after it has been accepted (unless it has a deadline, but my logic should ensure that any job with a deadline is always completable right away).
- There are also some QoL tweaks you can enable if you'd like, such as instant 3DMark results and portable software.
- Some story jobs, particularly earlier ones in the list, might only appear when others before it have been completed. Logic accounts for this and your manual client's location categories will show which ones are connected.
- One story character, the Submariner, is excluded due to their first job having a deadline, therefore not guaranteeing that you can start that job line before it expires.
- Your Bongle rating will never matter, unless you want to do randomized jobs to kill time.
